Tutorial 1 — Criando uma página HTML

O HTML é utilizado para organizar o conteúdo de uma página web.

Passo a passo

  1. Abra o Visual Studio Code.
  2. Crie um arquivo chamado exemplo.html.
  3. Digite a estrutura HTML abaixo.
  4. Salve o arquivo.
  5. Abra o arquivo no navegador.

Exemplo de código

<!DOCTYPE html>
<html lang="pt-BR">
<head>
    <meta charset="UTF-8">
    <title>Minha primeira página</title>
</head>
<body>
    <h1>Olá, mundo!</h1>
    <p>Minha primeira página HTML.</p>
</body>
</html>

Ao abrir o arquivo, o navegador mostrará um título e um parágrafo.

Tutorial 2 — Aplicando estilos com CSS

O CSS é responsável pela aparência visual de uma página.

Passo a passo

  1. Crie um arquivo chamado estilo.css.
  2. Adicione as regras CSS abaixo.
  3. Salve o arquivo na mesma pasta do HTML.
  4. Conecte o CSS ao arquivo HTML.

Exemplo de CSS

body {
    background-color: #f4f4f4;
    font-family: Arial, sans-serif;
}

h1 {
    color: #071b30;
    text-align: center;
}

p {
    font-size: 18px;
}

Como conectar o CSS

Adicione esta linha dentro da seção head do HTML: 

<link rel="stylesheet" href="estilo.css">

Assim, o navegador aplicará os estilos definidos no arquivo CSS.

Tutorial 3 — Interatividade com JavaScript

O JavaScript permite criar funcionalidades interativas, como botões, menus e formulários.

Passo a passo

  1. Crie um arquivo chamado exemplo.js.
  2. Adicione o código JavaScript abaixo.
  3. Crie um botão no arquivo HTML.
  4. Conecte o JavaScript ao HTML.
  5. Abra a página e clique no botão.

Código JavaScript

function mostrarMensagem() {
    alert("Bem-vindo ao Portal Tech!");
}

Botão HTML

<button onclick="mostrarMensagem()">
    Clique aqui
</button>

Conectando o JavaScript

<script src="exemplo.js"></script>

Coloque a tag script antes do fechamento da tag body. Ao clicar no botão, uma mensagem aparecerá na tela.
