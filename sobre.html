Sobre o Portal Tech

O Portal Tech é um projeto acadêmico desenvolvido para a disciplina de Front-End para Web.

O site foi criado com o objetivo de colocar em prática conhecimentos de desenvolvimento web, utilizando HTML, CSS e JavaScript.

Além do aprendizado técnico, o Portal Tech apresenta conteúdos educativos sobre tecnologia, programação e segurança digital.

Objetivo do projeto

O principal objetivo do Portal Tech é desenvolver um site com navegação entre diferentes páginas, organização visual e funcionalidades interativas.

O projeto também busca aplicar boas práticas de estruturação HTML, estilização com CSS e programação com JavaScript.

Tecnologias utilizadas

HTML5

Utilizado para estruturar o conteúdo das páginas, incluindo títulos, textos, imagens, links, tabelas e formulários.

CSS3

Responsável pela aparência visual do site, como cores, espaçamentos, organização dos elementos e adaptação a diferentes telas.

JavaScript

Utilizado para adicionar interatividade, como o menu de navegação, a pesquisa de conteúdos e o armazenamento local das mensagens do formulário.

Bootstrap

Biblioteca utilizada em partes do projeto para aplicar componentes e estilos de interface.

Funcionalidades do Portal Tech

  • Navegação entre dez páginas HTML.
  • Layout desenvolvido com CSS Grid e Flexbox.
  • Adaptação visual para diferentes tamanhos de tela.
  • Galeria de imagens sobre tecnologia.
  • Campo de pesquisa em páginas de conteúdo.
  • Agenda de estudos organizada em tabela.
  • Reprodução de conteúdos em áudio e vídeo.
  • Formulário com validação de campos.
  • Armazenamento de mensagens com localStorage.

Essas funcionalidades permitem aplicar diferentes conceitos estudados durante a disciplina.
